Getting there — the folder is hidden

.claude starts with a dot, so file pickers hide it by default. It is still reachable; you just have to ask for it by name.

  • macOS — click Choose folder above, then in the Finder dialog press ⇧⌘G, paste ~/.claude/projects, hit return, and pick a project folder. ⇧⌘. also toggles hidden files into view, in the dialog and in Finder.
  • Windows — type %USERPROFILE%\.claude\projects into the dialog's File name box and press Enter.
  • Linux — press CtrlL in the GTK dialog and type ~/.claude/projects, or CtrlH to show hidden files.

Prefer the terminal? Open the folder in your file manager, then drag a project onto the box above:
